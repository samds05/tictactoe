# Tic-Tac-Toe Game 🎮

A sleek, interactive, and responsive web-based **Tic-Tac-Toe** game built using vanilla front-end technologies. This project brings the classic experience to life with smooth animations, audio feedback, and a clean, responsive layout.

## 🚀 Live Demo
Check out the live game here: [Play Tic-Tac-Toe](http://dcode.epizy.com/)

## ✨ Features
* **Classic Gameplay:** Standard 3x3 grid following traditional rules. No extra gimmicks or power-ups.
* **Local Multi-player:** Designed for 2 players to play physically on the same device (pass-and-play).
* **Audio Effects:** Dynamic audio cues for game actions (clicks, wins, and draws).
* **Responsive Design:** Fully optimized for seamless play across mobile, tablet, and desktop viewports.
* **Asset Management:** Clean separation of logical scripts, styles, and multimedia elements.

## 📁 Project Structure
The repository is organized cleanly into modular assets:
```text
├── css/         # Custom stylesheets for design and responsiveness
├── img/         # Standard graphical assets and images
├── imga/        # Specialized image collections or animations
├── js/          # Core JavaScript logic managing the game engine and win states
├── sound/       # Immersive audio feedback files
└── index.html   # Main entry point and game layout structure
```

## 🛠️ Built With
* **HTML5:** Semantic structure for the layout and game board.
* **CSS3:** Flexbox/Grid alignment, layout sizing, and animations.
* **JavaScript (ES6):** Game loop logic, grid turn handling, and DOM manipulation.

## ⚙️ Getting Started

Follow these simple steps to run a copy of the project locally:

### Prerequisites
You only need a modern web browser installed on your computer or phone.

### Installation & Execution
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project directory:
   ```bash
   cd tictactoe
   ```
3. Open the `index.html` file in your preferred web browser:
   ```bash
   # On macOS
   open index.html
   
   # On Windows
   start index.html
   ```
